## 用户反馈

2026-10-19：Ctrl+1 可以设为一级标题，再次按相同快捷键不能取消，不方便。要求排查相关标题及其他格式逻辑，整理后对齐。

## 排查范围

- Ctrl+1–6、Ctrl+0 与段落菜单；同级取消、跨级切换和多段选区。
- 引用、无序/有序/任务列表，以及加粗、斜体、删除线、行内代码。
- 即时编辑与源码模式的语义一致性、撤销、嵌套结构与评论关联。
- 输入框、代码块与中文输入法中的快捷键边界。

## 验收标准

1. 相同级别标题再次触发回到正文，其他级别直接切换，文字保留。
2. 单次操作可一次撤销；选区、光标与已有评论关联不被意外破坏。
3. 两种编辑模式的行为符合对齐后的规则，不叠加重复的标题或列表标记。
4. 输入框与不适用的特殊内容不会误触文稿格式操作。

## 排查结果与实现

2026-10-19 产品回复“可以，干吧”，按收敛后的三项范围开始实现。此回复是开工授权，不是功能验收。

### 已定位的墨页问题

- 即时编辑标题调用 `wrapInHeadingCommand`，底层只有设置级别，没有同级取消分支。
- 引用、无序和有序列表调用包装命令，没有明确的取消和类型转换逻辑。
- 任务清单直接插入固定的“待办事项”，没有将当前内容转换成任务项。
- 源码模式格式命令直接添加标记；标题只处理第一行且缺少 h5/h6，行内格式重复执行会叠加标记。
- 段落菜单只列出 h1–h4，但快捷键说明支持 h1–h6。
- 全局格式快捷键仅对部分输入面板做隔离，查找等输入框仍存在误操作正文的路径。
- 代码块菜单插入空围栏，没有包住所选文字的处理。作为相关发现登记，暂不扩大本轮改动范围。

### Typora 对照与范围收敛

2026-10-19 查阅 [官方快捷键说明](https://support.typora.io/Shortcut-Keys/)、[任务清单说明](https://support.typora.io/Task-List/)和[代码块说明](https://support.typora.io/Code-Fences/)，并在本机 Typora 1.10.6 的新建合成文稿中进行 UI 对照。

实测确认同级标题再次触发回到正文、有序与无序列表直接转换、同类有序列表再次触发取消，以及任务清单菜单保留原文字且再次点击取消。另观察到该版本源码格式菜单和跨段标题命令的禁用规则；这些不是墨页必须照搬的要求，也不推广为全部 Typora 版本的行为。

产品随后明确：“也别粒度太细了，又不是让你一比一复刻，typora也有些内容我都不用的”。本轮以墨页常用功能的可逆操作为主，Typora 仅作为有疑问时的参考。停止扩大竞品细节研究。

已确认的本轮范围：

1. 标题 1–6：同级再次触发取消，不同级别直接切换；菜单与快捷键一致。
2. 引用及现有列表：同类可取消、不同列表可转换；任务清单保留原文字。
3. 修正上述操作涉及的重复标记与输入焦点问题，保证原文保留、一次撤销可恢复。

源码模式保留墨页现有能力；不因竞品对照直接禁用。更多快捷键、复杂嵌套与额外排版能力暂不纳入。

### 实现摘要

- `src/formatCommands.ts`：标题同级取消、跨级切换；引用取消；列表选中项切换、同类退出一层；任务项沿用原文。使用 ProseMirror 结构变换保留选区、行内格式和评论位置，不通过重新解析整篇文稿来转换格式。
- 列表中只选中部分项时，将选中部分切换类型，前后未选项保留。已完成任务在继续应用任务格式时保留勾选状态；转换为普通列表则移除任务状态，撤销可恢复。
- `src/sourceFormatting.ts`：补齐 h5/h6，多行选区按行处理并保留空行，重复应用相同标记时移除；加粗、斜体、删除线和行内代码支持常用选区的重复取消。格式操作单独形成撤销步骤。
- Ctrl+0 只清除标题层级，保留外层列表/引用和行内格式。多段标题选区全是目标级别时统一取消，否则统一设为目标级别。
- 段落菜单补齐五、六级标题；快捷键避免输入框、中文组合输入、长按重复触发和嵌入式代码编辑区的误操作。
- 代码、表格、图片、公式及混合复杂容器不强制做结构转换，保留原内容。复杂嵌套结构的全面排版转换与代码块插入方式不属于本轮交付。

### 产品验收操作

原功能候选由 `release/0.2.0-rc.2/Start-acceptance.cmd` 启动，使用独立 `acceptance-profile` 和自建 `acceptance.md`。后续已提供整合排版修复的 `release/0.2.0-rc.3/Start-acceptance.cmd`，桌面“墨页 格式修复候选版”现指向 rc.3；两个目录和文稿分别保留。

1. 在普通段落中按 Ctrl+1，再按一次：标题回到正文；试 Ctrl+2、Ctrl+5/6 和菜单中的对应命令。
2. 选择原文，从段落菜单依次切换无序、有序、任务清单，再次点击同类格式取消；检查原文字仍在，Ctrl+Z 可恢复。
3. 对带加粗的段落应用、取消引用，检查加粗和文字保留。
4. Ctrl+/ 切换源码，选中文字重复按 Ctrl+B，或选两行应用/取消列表；检查标记不叠加。
5. 在查找框或评论输入框按 Ctrl+1 / Ctrl+B，正文保持原样。
6. 可为选区加一条评论，再切换标题、引用或列表，检查评论仍关联原文。
