## 实现范围

- 工具栏“评论”开关与添加入口、右键添加、Ctrl+Alt+M；右栏独立于左侧大纲/文件栏，默认 300px，可拖动或用方向键调到 300–440px。
- 正文剩余宽度小于 520px 时使用右侧抽屉，支持 Esc 关闭、焦点返回、Tab 循环；两侧栏偏好互不改写。
- 文字范围评论、全文评论、纯文本回复、编辑、删除及 8 秒撤销、解决/重开、筛选；本地署名可修改。评论按原文位置排列，全文和失联评论置后。
- 正文高亮点击打开评论，卡片引用定位原文；范围重叠时显示线程选择器。收起右栏保留下划线。未发送输入随收起、切换与重启保留为本地草稿。
- 正文不加入评论标记。ProseMirror Decorations 与 transaction mapping 跟随编辑；范围完全删除/替换则保留评论并标记失联。撤销可以恢复对应历史锚点，复制粘贴不会复制或重新激活已失联批注。
- UTF-16 可见文本投影包含段落换行、上下文、块路径/摘要、投影摘要以及关联 ID。重开和模式往返先校验投影，再用明确引用与上下文定位；歧义保留为失联。手动“关联到所选文字”建立新关联。
- 源码模式支持全文评论、查看、回复、编辑和解决；不提供源码范围高亮。表格、代码、图片、公式等复杂选区提示使用全文评论。

## 保存、安全和恢复

配套文件为完整文稿名加 `.moye-comments.json`（例如 `笔记.md.moye-comments.json`），首次发布评论后建立；删除所有线程仍保留空容器与 revision，避免旧评论误复活。单独携带 Markdown 不包含评论；PDF/HTML 导出仍为正文。

- 只改评论时校验正文和配套文件的 hash，单独保存评论。测试包含 UTF-8 BOM、CRLF 和混合换行，原文字节及仅评论保存时的修改时间保持不变。
- 正文有修改且关闭自动保存时，评论先留本地草稿，Ctrl+S 才一同保存；不借发表评论偷偷保存正文。
- 串行保存固定正文和评论快照，先写本地恢复记录，再原子替换正文和评论。两文件不宣称事务原子性。
- 正文成功、评论失败会显示“正文已保存，评论待重试”，保留恢复数据并暂停自动重试；Ctrl+S 可以重试。重开仅在 hash 匹配时恢复未完成的评论写入，外部变化时停止恢复。
- 保存中继续输入时，回调只确认当次快照，较新的正文/评论继续 dirty，更新恢复草稿；文稿会话切换后忽略过期结果。
- 另存为复制评论并生成新 documentId，目标已有配套文件时独立报告冲突；取消不创建文件。外部修改同时监听正文与评论，提供载入磁盘版或另存为；明确丢弃时清除该文稿的未完成写入记录。
- 配套 JSON 损坏、未知 schema、非法结构、链接/目录和超限不会作为空评论覆盖。上限：8 MB、2000 线程、每线程 200 条消息、每条 10000 字、选区 20000 UTF-16 单元。
- sidecar 路径由主进程从已授权文稿路径推导，保留 IPC sender/grant 检查；拒绝 sidecar 链接或非普通文件。
- 原子替换遇 EPERM/EACCES/EBUSY 最多进行 5 次退避重试，最终失败保留原文件与恢复记录。没有删除原文来规避替换失败。已用故障注入验证；不能据此声称覆盖所有 OneDrive/防病毒软件占用情形。

## 产品验收步骤

1. 用独立候选入口打开示例文稿；确认右栏 300px 的宽度、卡片、字体与颜色合适，切换素白/暖纸/深夜再看一遍。
2. 选择一段正文，按 Ctrl+Alt+M，输入评论，Ctrl+Enter 发布；点击高亮与卡片引用确认双向定位。未选字时添加全文评论。
3. 回复、编辑、解决、筛选已解决、重新打开；删除一次再点“撤销删除”。
4. 收起右栏再打开，确认左栏不受影响；输入未发送评论后收起/重开，输入应保留。拖动右栏边界，并把窗口缩至最小尺寸检查抽屉。
5. 在引用前方和内部输入，删除整段再撤销；删除后仍保留的评论可选择新文字手动重新关联。
6. Ctrl+S 后关闭候选版，再从同一入口打开；检查评论和未发送输入仍在。另存为后新文件旁应有自己的评论文件。
7. 在写作设置关闭自动保存，修改正文再发表评论，磁盘正文应保持未保存直到 Ctrl+S；故障/外部改写场景已有自动化证据，可选择性使用合成文稿复验。

## 已知边界

- 暂不支持源码范围、复杂节点范围、多用户同步与合并、带批注导出；属于已认可第一版边界。
- 删除范围的精确撤销关联保留最近最多 100 个文档快照，累计约 500 万字符计量；超出保留窗口或引用出现歧义时保守失联，评论仍保留，可手动关联。
- 文稿在应用外单独改名/移动时，不扫描磁盘猜测配套文件；需用右栏“导入”选择对应 JSON。
- Windows 两文件写入和外部编辑不能成为跨进程原子事务；保存前与替换前检查并保留恢复记录，仍建议产品在自己的日常同步环境中验收。
