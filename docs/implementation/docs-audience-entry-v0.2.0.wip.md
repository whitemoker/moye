## 验收标准与步骤

1. 仓库首页优先展示软件下载、截图、使用说明和兼容性，完整开发命令集中到开发者与 AI 入口。
2. 首页可直接找到开发者与 AI 入口；入口可到达 AGENTS.md、文档规范、设计目录、实施目录及源码开发说明。
3. 开发入口说明产品设计与人机分工、当前文档流程、代码结构、运行和发布方式；保持已有产品验收边界。
4. 三个新增记录字段明确为可选，可按实际情况选择或全部省略；不要求补写历史记录或编造判断过程。
5. 检查新增与调整的内部链接、Markdown 内容和目录结构；本轮不修改应用源码、版本或发行包。
